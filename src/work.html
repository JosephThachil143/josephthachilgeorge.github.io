About

I'm a Security Engineer at TUI operating at a senior / lead level, working across the full breadth of security engineering — API, Mobile, Cloud and AI/GenAI. I lead security for the Mobile domain, running the monthly security forum and owning end-to-end architecture security reviews across the iOS, Android and Flutter platforms and the mobile backend.

Alongside this I lead organisation-wide security initiatives: I lead Threat Designer, an AI threat-modelling platform now used by 255 people (featured on the AWS Architecture Blog); led the first API security tooling in TUI's CI/CD pipeline; and, as part of the Security function in TUI's Modular Architecture, create and review security guidance, standards, best practices and checklists for Modular Web Architecture (MWA) and Modular Service Architecture (MSA).

I pair deep technical delivery with leadership — leading threat-modelling sessions and architecture reviews, running security forums with Information Security Managers, mentoring engineers, and building role-specific security learning paths. My current focus is AI/GenAI and mobile security, from GenAI threat modelling to AI-agent-assisted security via MCP.

BADE

Backend Architecture Discovery Engine

Developed a tool that auto-generates backend architecture diagrams by integrating observability, service catalog, cloud and CI data — eliminating stale, hand-drawn diagrams. Used to drive the security assessment of a large mobile backend (dozens of services across multiple trust layers), producing a layered trust view and surfacing shadow dependencies (undeclared runtime calls) that manual reviews miss. Self-service via a CI/CD template, OIDC-secured.

Case study

Authored an open-source platform (MIT) that discovers, maps and risk-scores machine identities — IAM roles, OIDC federations and CI/CD tokens — across AWS and GitLab/GitHub. Features a trust graph, blast-path simulation, trust-debt scoring, compliance checks and AI-assisted remediation. Full-stack: Python/FastAPI, React/TypeScript, Terraform.

Agentic AI

Creator — Agentic AI Security Skills (Open Source)

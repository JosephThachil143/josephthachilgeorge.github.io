# josephthachilgeorge.github.io

Personal cybersecurity portfolio for Joseph Thachil George, hosted on GitHub Pages
at [josephthachilgeorge.com](https://josephthachilgeorge.com).

## Files

| File | Purpose |
|------|---------|
| `index.html` | The full single-page portfolio |
| `styles.css` | Styling |
| `script.js` | Mobile nav + footer year |
| `CNAME` | Tells GitHub Pages to serve the site on the custom domain |

## Editing

Open `index.html` and replace the placeholder text (experience, projects,
publications, certifications, contact email) with your real details. Commit and
push — GitHub Pages redeploys automatically.

## Custom domain

The `CNAME` file sets the domain to `josephthachilgeorge.com`. DNS is managed at
Domainssaubillig with GitHub's A records for the apex and a `CNAME` for `www`.
